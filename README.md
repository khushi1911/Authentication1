# Authentication Level 1

A beginner-level authentication project built using Node.js and Express.js. The project demonstrates the basics of protecting application content through user authentication.

## Features

* User authentication
* Login-based access control
* Handling user credentials
* Server-side authentication logic
* Protected application content

## Tech Stack

* Node.js
* Express.js
* JavaScript
* HTML
* CSS

## How to Run

1. Clone the repository.
2. Install the required dependencies:

```bash
npm install
```

3. Start the application:

```bash
node index.js
```

4. Open the application in your browser.

## What I Learned

* Basics of authentication
* Handling login requests
* Working with Express.js
* Managing user access
* Server-side request handling

## Purpose

This project was created to understand the fundamentals of authentication and how web applications can restrict access to certain content.
